# AI Family Doctor Server

## 1. 作用

项目的后端业务模块，连接前端页面、大模型服务和数据库，承接用户健康咨询，组织多轮问答，并将回答以完整文本或流式形式返回给前端。

## 2. 负责工作

- 提供注册、登录、JWT 身份认证与接口权限校验。
- 校验并截断客户端提交的历史上下文，调用大模型生成回答；每轮流式请求独立管理 SSE 连接，通过异步线程池、用户级生成锁和超时机制控制生成过程。
- 保存问题全文、请求状态、性能指标及规则评分，并提供可选的 JSONL 请求录制能力，为测试模块的隔离回放提供样本。

当前聊天上下文由客户端携带，服务端不提供历史对话恢复；用户级生成锁仅在单个 JVM 内有效。健康回答与规则评分均不能作为医学诊断结论。

## 3. 结构介绍


| 内容 | 职责 |
| --- | --- |
| `controller/` | 账号、聊天和旧 SSE 演示接口入口 |
| `service/`、`service/impl/` | 用户业务、模型调用编排、异步生成、并发控制及问题与指标保存 |
| `stream/` | 单轮 SSE 推送、完成与失败通知、取消及连接关闭 |
| `bean/`、`mapper/` | 请求与响应对象、数据库实体及数据访问 |
| `context/` | 历史消息校验、完整轮次截断及上下文快照 |
| `traffic/` | 请求快照、用户标识 HMAC 处理、有界录制队列、JSONL 文件写入与保留清理 |
| `utils/` | DashScope 模型适配、Mock 输出、认证及提示词等辅助能力 |
| `config/` | 模型、异步线程池、评分及回放环境隔离等配置 |
